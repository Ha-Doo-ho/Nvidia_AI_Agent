★★★★★	VAE는 평균 주변의 영역을 Decoder가 학습한다. ★★★★★


VAE 2단계: 평균 μ와 분산σ²
log(σ²) 가 있다. 로그 분산이라는 의미이다.

① 일반 AE
일반 AE는 Encoder가 잠재 벡터 z를 직접 출력하였다. → 이는 한 점으로 고정되었기 때문에 문제가 있었다.
이미지 → Encoder → z → Decoder


② VAE
VAE의 Encoder는 z를 직접 출력하지 않고, ★z가 만들어질 확률분포의 평균(μ)과 분산(σ²)을 출력★한다.
이미지 → Encoder → 평균 μ → 분산 σ² → 이 분포에서 z를 뽑음 → Decoder


③ 수식으로 표현하면?
q( z | x ) = N( μ(x),  σ²(x) )


④ 평균  μ는 무엇인가?
평균은 해당 이미지가 잠재공간에서 위치할 중심이다. 

ex) 잠재공간이 2차원이라고 가정
운동화 이미지 → μ = [2.0, -1.0]
이것은 해당 운동화 이미지의 잠재 표현이 대략 다음 위치를 중심으로 한다는 의미이다. 
첫 번째 잠재축 중심:  2.0
두 번째 잠재축 중심: -1.0

일반 AE라면 이 ★값 자체를 잠재 벡터로 사용★한다.
z = [2.0, -1.0]

이것은 해당 운동화 이미지의 잠재 표현이 대략 다음 위치를 중심으로 한다는 뜻이다. 
첫 번째 잠재축 중심:  2.0
두 번째 잠재축 중심: -1.0
일반 AE라면 z = [2.0, -1.0] 이 값 자체를 잠재 벡터로 사용한다. 

VAE에서는 이 값이 잠재 벡터의 확정값이 아니라, 잠재 벡터가 만들어질 중심 위치이다.
z가 μ 주변에서 만들어짐


⑤ σ와 σ² 
σ는 표준편차,, σ²는 분산으로 평균을 중심으로 값이 어느 정도 퍼질 수 있는지를 나타낸다. 

ex)
μ = 2.0, σ = 0.1
다음처럼 평균과 매우 가까운 값들이 주로 만들어진다.
1.93, 2.02, 2.08, 1.97

혹은:
μ = 2.0, σ = 1.0 이면 더 넓은 범위의 값이 만들어질 수 있습니다.
0.9, 1.7, 2.6, 3.2

따라서 다음처럼 해석할 수 있다.
μ → 잠재공간의 중심 위치
σ → 그 중심에서 어느 정도 움직일 수 있는가


⑥이미지마다 평균과 분산이 따로 나온다.
평균과 분산은 모델 전체에 하나씩 존재하는 값이 아니다. 입력 이미지마다 다르게 만들어집니다.
예를 들어 잠재 차원이 2라면:

운동화 이미지 A
μ = [2.0, -1.0], σ = [0.2, 0.4] --> 첫 번째 차원은 평균: 2.0, 표준편차: 0.2 이다. 
약 95%(정규분포를 따르는 데이터의 범위는 표준편차의 2배이다.): 1.6~2.4  
그 밖의 값도 가능하지만 확률이 낮다.

운동화 이미지 B
μ = [2.3, -0.8], σ = [0.3, 0.5]

가방 이미지 C
μ = [-1.2, 1.7], σ = [0.4, 0.2]

Encoder는 각 이미지를 보고 그 이미지에 알맞은 평균과 분산을 계산한다.
같은 Encoder 사용 + 서로 다른 입력 이미지 → 서로 다른 μ와 σ


⑦ 잠재 차원이 32라면 무엇이 출력되는가?
 기존 Dense AE의 잠재 차원은 32였다. → LATENT_DIM = 32

일반 AE의 Encoder출력은 다음과 같다. z(잠재벡터) :32개
VAE의 Encoder 출력은 다음과 같다. → μ:  32개, σ²: 32개
총 64개의 값이 나오지만 잠재 벡터가 64차원인 것은 아니다. !!! 이걸 주의할 것.

μ 32개 + σ² 32개 → 32차원 확률분수를 정의. 
그 확률분포에서 → 32차원 z를 샘플링.

잠재 차원	평균		분산
1		μ₁ 		        σ²/¹
2		μ₂		        σ²/²
3		μ₃		        σ⅔
... 	... 		    ...
32		μ₃₂		        σ²/³²


⑧ 실제 코드에서는 왜 로그 분산을 출력하는가?
실제 VAE에서는 보통 분산 σ²를 직접 출력하지 않고 다음 2개의 값을 출력한다.
z_mean → μ ,   z_log_var  → log(σ²)

왜?
1. 분산은 반드시 0보다 커야 한다. 분산은 제곱을 붙이므로 음수가 불가능하다.
하지만 일반 Dense계층의 출력은 음수가 나올 수 있다. → Dense 출력 예: [-2.1, 0.3, 1.7, -0.8, ...]
이 값을 바로 분산으로 사용하면 음수 분산이 생길 수 있다. 그러나 로그 분산은 음수여도 된다.
다시 지수 함수로 변환하면 항상 양수가 되기 때문이다.

2. 로그를 사용하면 계산이 더 안정적이다. '
알다시피 분산은 ㅈㄴ 클 수도 있다. numpy는 소수 계산에 강하기 때문에 log를 이용해서 작은 수로 두는 것이 쉽다.


⑨ 로그 분산에서 표준편차를 계산하는 방법
샘플링할 때는 분산이 아니라 표준편차 σ가 필요 하다.
코드로 다음과 같이 치면 된다. ▶ sigma = tf.exp(0.5 * z_log_var)
