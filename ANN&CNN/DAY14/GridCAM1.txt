1. 혼동 행렬 (Confusion Matrix) : "성적표 및 오답 통계"
목적: 모델이 '어떤 종류의 문제'를 헷갈려하는지 전체적인 통계를 확인합니다.

작동 방식: 수천 장의 테스트 데이터를 한 번에 채점해서 표(행렬)로 만듭니다.

비유: 학생의 전체 모의고사 성적표입니다. "이 학생은 미적분 문제는 다 맞히는데, 유독 기하와 벡터 문제만 나오면 확률과 통계로 착각해서 틀리네?" 하고 전반적인 취약 과목(클래스)을 찾아냅니다.

시각화 형태: 앞서 보여드린 파란색 바둑판 모양의 숫자 표입니다.

2. Grad-CAM : "학생의 시선 추적 (X-ray)"
목적: 모델이 특정 사진을 보고 '왜 그런 정답을 내렸는지(어디를 보고 판단했는지)' 그 이유를 시각적으로 확인합니다.

작동 방식: 테스트 데이터 전체가 아니라, '특정 사진 1장'을 모델에 넣고 모델의 시선(가중치의 활성화 정도)을 추적합니다.

비유: 학생이 특정 시험 문제 하나를 풀 때 '어느 단어에 밑줄을 치고 집중해서 보았는지' 시선을 추적하는 것입니다.

예를 들어 모델이 강아지 사진을 보고 "강아지 99%"라고 정답을 맞혔을 때, Grad-CAM을 켜보면 모델이 강아지의 '귀'와 '코' 부분을 빨갛게 뚫어져라 쳐다보고 있었다는 것을 알 수 있습니다.
즉 너가 답을 냈는데, 대체 무엇을 보고 그 답을 냈는지를 시각화 한 것이다. 
개념 → target → target layer → grad_model → gradient → heatmap

시각화 형태: 원본 사진 위에 중요한 부분을 빨갛게(또는 노랗게) 칠해주는 히트맵(열화상 카메라 같은 이미지) 형태입니다.

Target의 진짜 의미
이 Target은 무조건 정답을 의미하는 것이 아니다 라는 것. 
Grad-CAM에서 Target이란 모델에게 물어볼 질문(어느 클래스 점수가 높아진 이유를 볼 것인가?)을 볼 것인가? 

동일한 사진 1장을 두고도, 어떤 Target을 고르느냐에 따라 Grad-CAM이 보여주는 시선(Heatmap)은 완전히 달라진다. 
1.pred_target (모델이 예측한 클래스): --> 코드 상에서 predict
    질문: 정답은 티셔츠야. 그런데, 너는 이 사진을 셔츠라고 예측했어. 왜 너는 왜 이 사진을 셔츠라고 확신했어? 
    목적: 모델이 스스로 선택한 근거를 확인한다. 

2. true_target (실제 정답 클래스): --> 코드 상에서 y_test
    질문: 이사진의 진짜 정답은 티셔츠야. 티셔츠의 흔적은 너가 찾았을 때 어디에 얼마나 있었어? 
    목적: 모델이 정답을 맞히지 못했을 때, 정답의 근거를 놓쳤거나 약하게 본 부분을 찾아낸다.

3. alt_target(비교할 2순위 후보)
    질문: 2번째로 점수가 높았던 것은 코트였어. 코트라고 생각한 이유는 뭐야?
    목적: 비슷한 클래스(셔츠 vs 코트 --> 어차피 답은 티셔츠인데, 예측 2순위가 코트였음. 코트라고 생각한 이유는 뭐야?) 사이에서 모델이 어떤 경계에서 헷갈렸는지 비교한다.

Grad-CAM의 작동 개요
Grad-CAM은 모델을 다시 학습시킬 필요 없이, 이미 완료된 판단을 사후에 설명해 주는 도구임을 강조한다. 

작동 3단계
    1. 목표 클래스 선택: 앞서 배운 target score(예: 셔츠) 증 하나를 고른다. 
    2. 중요 위치 계산: 모델의 ★★맨 마지막 합성곱(Conv2D)층★★에서 뽑아낸 특징과, 우리가 선택한 목표 클래스의 기울기를 결합하여 계산
    3. 히트맵 표시: 선택한 target에 긍정적인(양의 가중치)영향을 크게 미친 위치일수록 열화상 카메라처럼 진하게 칠해줌 (열화상과 거의 유사함)
    주의할 점: 이 히트맵은 물체의 완벽하고 정확한 테두리를 그려주는 것이 아닙니다. 모델 내부에서 일어난 계산의 흔적을 보여주는 '거친 사후 설명'일 뿐이다.

Target변경에 따른 결과 비교 (실전 예시)

Target은 무조건 실제 정답을 뜻하지 않는다 는 것이다. Target이 무엇을 Target하냐는 것이다. (Predict, Target)
target = pred_target (코드 상의 predict)로 설정한 경우: 
    히트맵은 모델이 62%라는 높은 점수를 준 이유. 즉 "어떤 위치가 셔츠 점수를 높이는 데 기여 했는지"를 보여준다. 

target = true_target (코드상의 y_test)로 설정한 경우
    히트맵이 티셔츠 점수(31%)에 기여한 위치는 어디인지 즉, 정답 내용을 판단했을 때 기여한 위치는 어디인지를 보여준다.
